# Project: Crossroads

Project: Crossroads is an experimental Fallout 3 multiplayer project built
from the useful foundations of the abandoned VaultMP project and redesigned
for current private testing.

## Private multiplayer tester

The current tester targets:

- Fallout 3: Game of the Year Edition
- Fallout3.exe 1.7.0.3 produced by the Fallout Anniversary Patcher
- FOSE 1.2 beta 2
- Windows

Download the
[Project: Crossroads private network tester](downloads/Project-Crossroads-Private-Network-Test.zip),
extract it to a normal folder, and follow the included README.

This initial download includes the Crossroads automatic updater. After setup,
the launcher checks this repository's update channel and installs verified
Crossroads program updates without requiring testers to download replacement
ZIP files.

## Current status

This is a trusted-friend development test, not a finished public multiplayer
release. Current work focuses on private-session connectivity, remote-player
visibility, transform synchronization, motion smoothing, and safe cleanup.
Combat, quests, inventory, doors, cell transitions, NPC synchronization, and
full animation synchronization remain incomplete.

Project: Crossroads does not redistribute Fallout 3, FOSE, or the Fallout
Anniversary Patcher.
